- **What the donor is.** "AfrikaBurn Contributors App" / "Quagga Portal" — a three-app Turborepo replacing Google Forms + WhatsApp + spreadsheets for AfrikaBurn theme-camp registration. - **Three apps, one account pool, three Vercel deployments** (README.md:20-63, AGENTS.md:41-43, docs/build-spec.md:49-52): `apps/web` participant app, port 3000, teal accent, `app.quagga.ryanjnoble.dev`; `apps/org` organiser console, port 3001, apricot (`.org-accent` class on `<html>`), `org.quagga.ryanjnoble.dev`; `apps/suppliers` supplier portal, port 3002, sage, `suppliers.quagga.ryanjnoble.dev`. Two hard rules: **`@quagga/core` never imports `@quagga/db`** (keeps 872 core tests DB-free), and **`@quagga/core/report-server` is a separate export subpath** because it reads `GITHUB_TOKEN` and pulls the Anthropic SDK — re-exporting from the barrel would ship the issue-filing machinery into every browser bundle (docs/architecture.md:85-88).
