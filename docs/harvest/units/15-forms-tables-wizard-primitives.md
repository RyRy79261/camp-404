### 1 + 3 — table and responsive table (the cheapest real win)
`table.tsx` exports exactly `Table, TableHeader, TableBody, TableFooter, TableHead, TableRow, TableCell, TableCaption` (:109-118), imports only `react` + `../lib/utils`. The root wraps in `relative w-full overflow-x-auto` (:10) — the bit that matters most for mobile-first. `TableRow` is `border-b transition-colors hover:bg-muted/50 data-[state=selected]:bg-muted`, `TableHead` uses `text-muted-foreground`; all resolve in `packages/ui/src/styles/globals.css`.

`ResponsiveDataTable` imports only react, lucide-react, `./table`, `cn`. `ResponsiveColumn<T> = { id, header, cell, role?, mobileHidden?, hideHeader?, align?, cellClassName?, headClassName? }`; `ResponsiveColumnRole = "title" | "badge" | "actions" | "default"`. `projectColumnsToCard<T>()` (:82) is exported separately as a pure function → `{title, badges, actions, pairs, hidden}`. Desktop `<table>` at `hidden md:block` (:197), mobile `<ul>/<li>` at `md:hidden` (:263) — **both layouts always in the DOM**, so every cell renderer runs twice per row and Playwright needs `.filter({ visible: true })`. `renderExpanded` adds a chevron column (`colSpan = columns.length + (expandable ? 1 : 0)`). Gotchas: `align: "center"` silently becomes `text-right` in the card (:318-323); the empty branch only fires if `emptyState` is actually passed (:190).
**Do NOT rewrite the shipped roster onto it in the same PR** — `roster-table.tsx` (headers Member/Handle/Country/Role at :41/:44/:47/:50) and `roster-list.tsx` are not the same column set; the list renders one sub-line plus a role emoji. Land the primitive, use it for the *next* table.

### 4 — the microphone leak (verified by reading the code, not taken on trust)
`apps/web/components/voice/use-voice-recorder.ts`: the unmount cleanup (`:77-94`) reads `recorderRef`/`streamRef`/`audioCtxRef` **synchronously**. `start()` awaits `navigator.mediaDevices.getUserMedia` at `:117`, then assigns `streamRef.current = stream` at `:124` and builds the AudioContext at `:129-138` with **no `mountedRef` re-check in between**. `safeSet` (`:96-98`) guards `setState` only. Unmount while the permission prompt is open ⇒ both the stream and the AudioContext survive and the OS mic indicator stays lit. Fix: re-check `mountedRef.current` immediately after the await; if false, `stream.getTracks().forEach(t => t.stop())` and return before touching any ref. Donor guard: `use-dictation.ts:118-121`.
Also add `supported = typeof MediaRecorder !== "undefined" && Boolean(navigator.mediaDevices?.getUserMedia)` so `DictatePill` can hide instead of failing after the tap (today `pickMimeType()` returns `undefined` at `:47` and the member finds out post-permission). And add the disclosure line — `recorder-panel.tsx` has none, and the clip does leave the device for Groq.

### 5 — autosave that cannot lie
`builder-canvas.tsx` `persist()` snapshots `previous`, sets optimistically, awaits `updateDefinitionAction` inside `useTransition`, toasts + rolls back on failure. The footer at `:405-416` renders `{pending ? "Saving…" : "Saved"}` — a bare negation, so a **rejected** save lands on the literal string "Saved", and so does first paint. Port the algorithm, not the file (the donor's is welded to six `SECTION_KEYS`): a `SaveState = "idle"|"saving"|"saved"|"error"` plus `lastSavedAt`; a `flushRef` so concurrent callers **join** the in-flight save (`if (flushRef.current) return flushRef.current`, :180) cleared in an identity-checked `.finally` (:210-213); `dirtyRef.current = false` **before** the await so a mid-write edit is caught by the next pass; `dirtyRef = true` on failure so a later flush retries; submit re-marks dirty and awaits a full flush before calling the server. Same PR: the spinner at `builder-canvas.tsx:410` is bare `animate-spin`, not motion-safe.
